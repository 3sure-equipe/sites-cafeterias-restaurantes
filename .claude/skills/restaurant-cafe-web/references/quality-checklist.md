# Checklist de qualidade e aceite

## Conteúdo e marca
- [ ] Nome, logo e identidade visual corretos.
- [ ] Paleta confirmada com o cliente.
- [ ] Endereço, horários, telefone e redes sociais conferidos.
- [ ] Produtos, descrições e preços aprovados.
- [ ] Nenhuma avaliação ou promoção inventada.
- [ ] Imagens correspondem aos produtos e ao estabelecimento.

## Experiência
- [ ] Navegação clara em celular e desktop.
- [ ] Cardápio legível, categorizado e fácil de percorrer.
- [ ] CTA principal visível e funcional.
- [ ] WhatsApp abre o número correto e mensagem esperada.
- [ ] Mapa e endereço correspondem ao local correto.
- [ ] Galeria utilizável por toque e teclado.
- [ ] Links externos identificáveis.
- [ ] Estados vazios e conteúdo pendente tratados.

## Acessibilidade
- [ ] HTML semântico.
- [ ] Contraste suficiente.
- [ ] Foco de teclado visível.
- [ ] Imagens informativas com texto alternativo.
- [ ] Controles com rótulos acessíveis.
- [ ] Movimento reduzido respeitado.

## SEO e desempenho
- [ ] Title e description específicos.
- [ ] Open Graph e favicon.
- [ ] Imagens otimizadas e dimensões definidas.
- [ ] Sem imagens quebradas ou layout shift evitável.
- [ ] Sitemap/robots quando aplicável.
- [ ] Dados locais estruturados apenas com dados confirmados.

## Engenharia
- [ ] Lint executado.
- [ ] Typecheck executado.
- [ ] Build executado.
- [ ] Links e ações testados.
- [ ] Sem erros relevantes no console.
- [ ] `.env` e credenciais fora do Git.
- [ ] README/guia do projeto atualizado quando necessário.

## Entrega
- [ ] Resumo do que foi feito.
- [ ] Testes e resultados informados.
- [ ] Pendências de conteúdo listadas.
- [ ] Instruções para executar localmente.
- [ ] Deploy só declarado como concluído após verificação.
