# Pacote GitHub — Chonoko

Este pacote contém dois conjuntos separados:

- `.claude/skills/restaurant-cafe-web/`: Skill reutilizável para sites de restaurantes e cafeterias.
- `clients/chonoko/`: materiais e guia visual específicos da Chonoko.

## Como integrar

Copie o conteúdo deste pacote para a raiz do repositório GitHub existente, preservando os caminhos.

A estrutura final deve conter:
- `.claude/skills/restaurant-cafe-web/SKILL.md`
- `clients/chonoko/brand-guide.md`
- `clients/chonoko/assets/` com as três imagens fornecidas.

Depois faça commit/push. Abra uma nova sessão do Claude Code no repositório e peça para usar `/restaurant-cafe-web` e ler `clients/chonoko/brand-guide.md`.

## Observação

As cores do guia são aproximações visuais. Confirme com a cafeteria antes de tratá-las como paleta oficial.
